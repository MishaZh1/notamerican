# NOTAMERICAN: The General Knowledge Powerhouse 🌍🧠

## 🚀 Vision
To build the most addictive, gamified, and effective general knowledge learning platform in the world. Think **Duolingo meets Trivial Pursuit**, but with a focus on global (Not-just-American) perspective.

---

## 🔁 The Core Loop
1.  **Vibe Check**: Enter a category or "Daily Mix".
2.  **The Match**: Quick-fire interactive sessions (Multiple Choice, Mix-and-Match, Flag ID).
3.  **Reward**: Earn XP, extend your 🔥 streak, and climb the Leaderboard.
4.  **Meta-Game**: Unlock new categories, customize your profile, and join weekly leagues.

---

## 🎯 Feature Roadmap

### Phase 1: The Foundation (Current)
- [x] Basic Quiz Engine (Multiple Choice).
- [x] Mix & Match Game Mode.
- [x] Seed content for Science, History, Geography, etc.
- [x] Authentication (Supabase).
- [x] Flat 2D "Agent Marco" (Border Agent) Mascot UI integration.

### Phase 2: Gamification (High Priority) ⚡
- [ ] **XP & Levels**: Every correct answer grants XP. Level up to show off status.
- [ ] **Streak System**: Visual fire indicator on Home/Play pages.
- [ ] **Daily Quests**: "Complete 3 games today", "Score 100% in Geography".
- [ ] **Heart System**: Lose a heart for wrong answers (refill over time or with XP).
- [ ] **The Digital Passport**: A dedicated UI section showing all the stamps you've earned from different countries/categories.
- [ ] **Sound Effects**: Tactile "ping" for correct, "thump" for wrong, and a satisfying "thud" for a passport stamp.

### Phase 3: Content Depth 📚
- [ ] **Map Explorer**: Tap the country on a map.
- [ ] **Photo Quiz**: Identify landmarks, historical figures, or art.
- [ ] **Dynamic Difficulty**: Adjust questions based on user's past performance.
- [ ] **AI-Powered Categories**: Users can request *any* topic (e.g., "19th Century French Poets") and get a generated quiz.

### Phase 4: Social & Viral 🏆
- [ ] **Weekly Leagues**: Bronze -> Silver -> Gold -> Obsidian.
- [ ] **Friend Challenges**: Compete head-to-head in real-time or asynchronously.
- [ ] **Shareable Milestones**: "I just hit a 30-day streak in History!" cards for social media.

---

## 🎨 Design Philosophy
- **Tactile & Juicy**: Every button should feel physical. Use `framer-motion` for bouncy transitions.
- **Vibrant & Friendly**: High-contrast colors, rounded corners, and a clean "Glassmorphism" look.
- **Mobile First**: Designed for quick sessions (1-3 minutes) on the go.

---

## 🛠 Tech & Architecture
- **Framework**: Next.js 14+ (App Router).
- **Database**: Supabase (PostgreSQL + Auth).
- **Styling**: Tailwind CSS + Custom Animations.
- **Icons**: Lucide React.
- **Assets**: Midjourney/DALL-E for the 3D Mascot and high-end icons.
