# IMPORANT: NAMING CONVENTION

The application name is **NOTA MERICAN**.
It is NOT "NotAmerican", "NotaAmerican", or "Not American".

**CORRECT USAGE:**
- **NOTA MERICAN** (All caps or Title Case depending on context, but space is mandatory)
- **Nota Merican**

**INCORRECT USAGE:**
- NotAmerican
- notamerican (except for file/package names where lowercase is required)
- Not American

Please ensure this is respected in all visible UI text, titles, and documentation.
